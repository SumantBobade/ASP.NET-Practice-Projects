# Project 1: Calculator

A simple desktop calculator built using C# and .NET Windows Forms. This application provides basic arithmetic operations including addition, subtraction, multiplication, and division through an intuitive graphical user interface.

## Features

* Addition, subtraction, multiplication, and division
* Clean and user-friendly interface
* Real-time input display
* Clear button to reset calculations
* Built with C# and .NET WinForms

## Technologies Used

* C#
* .NET
* Windows Forms (WinForms)
* Visual Studio 2022

## Getting Started

1. Clone the repository.
2. Open the solution in Visual Studio.
3. Build and run the project.
